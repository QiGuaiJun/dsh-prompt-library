# 提示词卡（dsh-prompt-library）

把常用的测试提示词收藏起来，点一下就能填进对话框复用。

## 入口

**输入框工具条上的「☆ 提示词卡」按钮**——在「完全权限」右边、模型选择左边。
点一下打开浮层面板，再点一下（或按 × / 点遮罩）关闭。

- **搜索**：匹配标题 + 正文 + 标签，输入即时过滤

- **置顶优先**：置顶的条目带 📌，永远排最前；其余按最近修改倒序
- **点卡片** → 进详情页
- **不知道怎么选？点最上面那条虚线按钮**（下面单独一节讲）

| 按钮 | 作用 |

## 新建

右上角「新建」→ 填正文（必填）、标题（留空自动取正文首个非空行前 60 字）、标签、**什么时候用**、来源、星标 → 保存。

**标签录入**：用英文逗号、中文逗号或回车分隔，自动去重，单个标签最长 40 字，最多 24 个。

**「什么时候用」这一栏值得花 10 秒填。** 它是一句话的场景说明，比如「先对齐再出方案，避免一次给出偏离喜好的三版」。两个作用：

1. 列表卡片上直接显示这一行，你自己扫一眼就知道该用哪条
2. 用上面那个「说不清要什么？让 AI 先问清楚」时，这句话会被拼进给 AI 的收藏目录里——**AI 就是靠它判断该不该选这条的**。只填标题的话，AI 只能猜

不填也能用，只是那条在引导里会少一个判断依据。

## 不知道该用哪条？让库里挑一条

列表页最上面那条虚线按钮——**「不知道下一句说什么？让库里挑一条给我」**。

你会在这些时候用得上它：

- 我只知道"我想要个能帮我管客户的小工具"，说不清第一版该做哪些功能
- 我在做决定，但不知道该怎么让 AI 帮我想清楚
- 我根本不知道自己卡在哪，只知道现在这个方向不对
- 我看代码遇到 bug，想系统排查但不知道从哪儿说起

**点一下会发生什么**：面板直接关掉，输入框里已经填好了东西，你**按回车发送**就行。插件读一遍你当前的对话，在**本机**给你收藏的提示词打分，然后按匹配程度走三种不同的路：

| 情况 | 填进输入框的是什么 |
|---|---|
| **有一条明显对得上** | 就一句话 + **那一条的正文全文**（约 75 字）。发送就行；后面括号里留了几个备选标题，不对路说一声就能换 |
| **有几条像，但拿不准是哪条** | 列出这几条的标题和「什么时候用」（压到一行，约 300 字），让对话里的 AI 挑 1 条、说明为什么，然后**直接开始做** |
| **收藏是空的** | 退回「一次一问」的追问流程（见下），跟收藏无关，照样有效 |

三种情况都**不会**很长——最多三百来字。全部计算都在你本机完成，不联网、不调模型、不发任何请求。

**它不会把你前面的对话再抄一遍。** 这是有意的：你正在聊的这个 AI 本来就看得到前面几轮，抄过去纯属占篇幅、还会把重点埋掉。它只补一件 AI 确实看不到的东西——**你在输入框里写了一半、还没发送的那段话**：

> 另外我在输入框里写了一半（这部分你之前没看到）：……

所以：想到一半、写到一半就直接点它，不用先清空输入框。

**追问流程长什么样**（出现在「收藏是空的」时）：AI 会**一次问你一个问题**，每题给你 2-3 个具体选项让你挑。问两三句后会给你一个能立刻看到的东西让你判断对不对——不对就直接说「不对」，它会猜原因，而不是重新问你要什么。

两个细节：

- **输入框里已经有内容时**，会先问你一句「要替换吗」，点取消什么都不动；点确定才会把那段话带上重写
- **填完面板会自动关**，并在屏幕下方留一条提示告诉你是挑中了哪条、还是只给了候选。这条提示就是「填进去了」的证据——看到它再按回车

> 三种分支的具体文本、为什么闸门设得这么严（宁可只给候选，也不自信地给错一条），见开发设计文档 6.1 节。

## 从对话里收藏

每条**用户消息上方**和**助手消息下方**都有「存为提示词」按钮：

- 点开后正文已预填好该消息的内容，你补齐标题/标签即可
- 用户消息的来源自动标为「用户提示词」，助手消息自动标为「助手回复」
- 助手消息只取**正文文本块**，跳过思考过程（reasoning）和工具调用

## 数据存放

存在浏览器 `localStorage`，键名 `dsh:prompt-library:v1`。**只在本机**，不上云、不跨设备。

### 导出 / 导入

- **刷新**：重新从本机读一次数据。如果你在别的标签页改过提示词、或者页面长时间开着，点它同步一下；平时打开面板会自动读一次，不需要手动点
- **导出**：下载 `prompt-library.json`
- **导入**：弹窗里有两条等价的路——**「选择 JSON 文件…」** 或 **直接把 JSON 内容粘进下面的框**。两条都**按 id 合并**：同 id 覆盖，新 id 追加。如果选文件点了没反应（桌面版偶发），直接用粘贴那条。
- 导入失败会明确告诉你原因（不是合法 JSON / 文件里没有可用条目），不会再出现"点了没动静"。

导出文件结构：

```json
{
  "version": 1,
  "prompts": [
    {
      "id": "p_lq3k9x_a1b2c3",
      "title": "接口用例生成",
      "content": "请根据以下接口文档…",
      "tags": ["自动化", "接口"],
      "note": "配合 V3 网关用",
      "source": "手动新建",
      "starred": false,
      "pinned": false,
      "createdAt": "2026-11-20T08:12:33.000Z",
      "updatedAt": "2026-11-20T08:12:33.000Z"
    }
  ]
}
```

## 边界

| 项 | 限制 |
|---|---|
| 正文 | 必填，建议 ≤ 200000 字符 |
| 标题 | ≤ 160 字符（超长自动截断到 60 字用于显示） |
| 标签数 | ≤ 24 个 |
| 单个标签 | ≤ 40 字符 |

数据损坏（JSON 不合法、结构不符）时自动回退空列表，不会崩。

## 常见问题

**点「填入对话」提示"当前没有可用的对话输入框"**
→ 面板必须在某个会话里打开；新开一个会话或切回已有会话再试。

**刷新后提示词还在吗**
→ 在。存在浏览器 localStorage 里，除非清空浏览器站点数据。

**换了浏览器/电脑怎么迁移**
→ 用「导出」下载 JSON，在另一台用「导入」。

**面板配色跟主题对得上吗**
→ 对。面板会自动跟随 DSH 当前的明暗主题（含"跟随系统"），系统是浅色但 DSH 选了深色时，
面板仍是深色——它跟的是 DSH 的主题偏好，不是操作系统。
