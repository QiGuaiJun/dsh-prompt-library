# 提示词卡（dsh-prompt-library）

把常用的测试提示词收藏起来，点一下就能填进对话框复用。

## 入口

**输入框工具条上的「☆ 提示词卡」按钮**——在「完全权限」右边、模型选择左边。
点一下打开浮层面板，再点一下（或按 × / 点遮罩）关闭。

- **搜索**：匹配标题 + 正文 + 标签，输入即时过滤

- **置顶优先**：置顶的条目带 📌，永远排最前；其余按最近修改倒序
- **点卡片** → 进详情页
- **不知道怎么选？点最上面那条虚线按钮**（下面单独一节讲）

| 按钮 | 作用 |
|---|---|
| **复制** | 把正文复制到系统剪贴板 |
| **填入对话** | 把正文**整条替换**当前输入框内容，然后面板自动关闭 |
| **编辑** | 打开编辑框，可改标题/正文/标签/来源/星标 |
| **置顶 / 取消置顶** | 切换置顶，列表里置顶的排最前 |
| **删除** | 二次确认后删除 |

## 新建

右上角「新建」→ 填正文（必填）、标题（留空自动取正文首个非空行前 60 字）、标签、来源、星标 → 保存。

**标签录入**：用英文逗号、中文逗号或回车分隔，自动去重，单个标签最长 40 字，最多 24 个。

## 不知道该用哪条？让 AI 先问清楚

列表页最上面那条虚线按钮——**「说不清要什么？让 AI 先问清楚」**。

你会在这些时候用得上它：

- 我只知道"我想要个能帮我管客户的小工具"，说不清第一版该做哪些功能
- 我在做决定，但不知道该怎么让 AI 帮我想清楚
- 我根本不知道自己卡在哪，只知道现在这个方向不对

**点一下会发生什么**：插件往输入框里填一段话（你不用自己写），按回车发出去，AI 就会开始**一次问你一个问题**，每题给你 2-3 个具体选项让你挑。问两三句后会给你一个能立刻看到的东西让你判断对不对——不对就直接说「不对」，它会猜原因，而不是重新问你要什么。

这段话里还会附上你收藏的提示词目录（只有标题、一句「什么时候用」和标签，不含正文）。AI 在问的过程中发现某条正好用得上，会把它改写成一段你能直接发出去的指令，并告诉你为什么选它；没有合适的就明说缺什么，不会硬凑。

两个细节：

- **输入框里已经有内容时**，会先问你一句「要替换吗」，点取消什么都不动
- **收藏是空的时候也能用**——前面那套「一次一问」的流程跟收藏无关，照样有效

> 这段文字长什么样、为什么不做成弹窗问卷，见开发设计文档 6.1 节。

## 从对话里收藏

每条**用户消息上方**和**助手消息下方**都有「存为提示词」按钮：

- 点开后正文已预填好该消息的内容，你补齐标题/标签即可
- 用户消息的来源自动标为「用户提示词」，助手消息自动标为「助手回复」
- 助手消息只取**正文文本块**，跳过思考过程（reasoning）和工具调用

## 数据存放

存在浏览器 `localStorage`，键名 `dsh:prompt-library:v1`。**只在本机**，不上云、不跨设备。

### 导出 / 导入

- **刷新**：重新从本机读一次数据。如果你在别的标签页改过提示词、或者页面长时间开着，点它同步一下；平时打开面板会自动读一次，不需要手动点
- **导出**：下载 `prompt-library.json`
- **导入**：弹窗里有两条等价的路——**「选择 JSON 文件…」** 或 **直接把 JSON 内容粘进下面的框**。两条都**按 id 合并**：同 id 覆盖，新 id 追加。如果选文件点了没反应（桌面版偶发），直接用粘贴那条。
- 导入失败会明确告诉你原因（不是合法 JSON / 文件里没有可用条目），不会再出现"点了没动静"。

导出文件结构：

```json
{
  "version": 1,
  "prompts": [
    {
      "id": "p_lq3k9x_a1b2c3",
      "title": "接口用例生成",
      "content": "请根据以下接口文档…",
      "tags": ["自动化", "接口"],
      "note": "配合 V3 网关用",
      "source": "手动新建",
      "starred": false,
      "pinned": false,
      "createdAt": "2026-11-20T08:12:33.000Z",
      "updatedAt": "2026-11-20T08:12:33.000Z"
    }
  ]
}
```

## 边界

| 项 | 限制 |
|---|---|
| 正文 | 必填，建议 ≤ 200000 字符 |
| 标题 | ≤ 160 字符（超长自动截断到 60 字用于显示） |
| 标签数 | ≤ 24 个 |
| 单个标签 | ≤ 40 字符 |

数据损坏（JSON 不合法、结构不符）时自动回退空列表，不会崩。

## 常见问题

**点「填入对话」提示"当前没有可用的对话输入框"**
→ 面板必须在某个会话里打开；新开一个会话或切回已有会话再试。

**刷新后提示词还在吗**
→ 在。存在浏览器 localStorage 里，除非清空浏览器站点数据。

**换了浏览器/电脑怎么迁移**
→ 用「导出」下载 JSON，在另一台用「导入」。

**面板配色跟主题对得上吗**
→ 对。面板会自动跟随 DSH 当前的明暗主题（含"跟随系统"），系统是浅色但 DSH 选了深色时，
面板仍是深色——它跟的是 DSH 的主题偏好，不是操作系统。
